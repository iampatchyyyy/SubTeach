❓ App User Guide & Help Center

Fool-Proof Application Capabilities

Welcome to SubTeach! Below is a categorised guide explaining everything you can accomplish inside the app.

📊 1. Absence Monitoring & Smart Substitutions

Log Absences & Recommend Well-Rested Teachers

When a teacher calls in sick or takes leave, go to Monitoring:

  • Full vs. Partial Absence: Choose whether the teacher is missing the entire day or specific class periods.
  • Automated Substitute Ranking: The app automatically evaluates available teachers and suggests optimal subs based on daily workload, fatigue, break times, and priority rules.
  • Time-Based Credit Approval: Substitution credits are held as "Incoming Credits" until the date and time of the subbed class pass, preventing premature credit accumulation.
  • Official Slips: Confirm assignments to generate printable official substitution slips with approval signature lines.
🗓️ 2. Schedule Matrix & Visual Editing

Manage Weekly Timetables on a 15-Minute Grid

Navigate to Schedules to view or edit faculty timetables:

  • Drag-and-Drop Edit Mode: Toggle "Enable Edit Mode" to drag class blocks along 15-minute intervals (00, 15, 30, 45).
  • Batch Editing: Select multiple class blocks using checkboxes to move or rename them all at once.
  • Break Period Priority: Regular scheduled class blocks automatically override break background blocks underneath if a teacher is assigned to teach during recess.
🎉 3. Special Events & Class Suspensions

Schedule Schoolwide or Department Events

Use the Event Maker for exams, foundation days, or assemblies:

  • Class Suspension Mode: Automatically hide regular classes during event hours and banner-mark the matrix.
  • Targeted Scopes: Apply events to all departments or isolate specific levels (e.g., JHS or SHS).
⚙️ 4. Priorities, Limits & Theme Settings

Customise Recommendation Algorithm & Visuals

Customize system behavior under Settings:

  • Reorderable Priority Rules: Drag conditions (e.g., Daily Sub Limits vs. Rest Periods) to change how candidate substitutes are ranked.
  • Substitution Limits: Enforce minimum or maximum numbers of classes a teacher can substitute in a single day.
  • Dark / Light Theme: Instantly switch themes from the clock bar or Settings menu.
🔥 5. Firebase Real-Time Cloud Syncing & JSON Backup

Cloud Integration & Disaster Recovery

Manage cloud sync and backups in the Data tab:

  • Firebase Syncing & Auto-Updates: Seamless real-time integration updates your app across devices automatically whenever changes are made.
  • Diff Preview & Confirmation: Preview and confirm differences between local and cloud/file states before saving or overwriting.
  • JSON Backup/Restore: Upload existing JSON backup files or download comprehensive backup snapshots.
